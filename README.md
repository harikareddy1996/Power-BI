Faculty & Student Workload Dashboard
Purpose
  -I built a Power BI dashboard using three CSV files — Students, Faculty, and Workload. 
  -The dashboard provides insights into faculty and student workload, helping leadership quickly identify overloaded departments, track trends, and make informed decisions about resource allocation.

Data Preparation
  -Connected and cleaned the data in Power Query.
  -Created relationships between tables.

How to Use
  -Open the .pbix file in Power BI Desktop.
  -Explore the visuals to analyze faculty and student workload trends and departmental insights.
